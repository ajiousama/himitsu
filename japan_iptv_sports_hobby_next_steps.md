# Japan IPTV Sports / Hobby Research Next Steps

This file tracks the next steps for sports and hobby category research.

## Scope

This registry is URL-free. It is meant to organize candidate groups only.

Covered groups:

- J SPORTS family
- SKY A family
- GAORA family
- Golf-related groups
- Combat sports groups
- Fishing groups
- Railway groups
- Igo / Shogi groups
- Travel / leisure groups
- Pet / lifestyle groups

## Rules

Do not add:

- Direct playback URLs
- Token, vhash, ac_tk, or signed values
- p2p or p5p entries
- Detailed premium playback slugs
- Private or hidden source data

Keep the research at group level:

- group name
- genre
- candidate system family
- source family
- decision status
- priority
- notes

## Suggested order

1. J SPORTS family
2. SKY A and GAORA family
3. Golf Network family
4. Fishing / railway / igo-shogi hobby groups
5. Combat sports and sports-adjacent groups
6. Low-priority lifestyle groups

## Decision guide

- A candidate: appears across multiple public GitHub lists as a category/system family, without needing detailed playback identifiers.
- B candidate: appears in one or two lists, useful for tracking but not ready for adoption.
- C reference: channel guide or EPG-only information.
- X exclude: p2p/p5p, signed-token dependent, private, or stale-only material.
