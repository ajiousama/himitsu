# Jun IPTV — M3U IPTV based mod

Personal test branch. The goal of alpha1 is only to prove that the stock M3U IPTV 3.0.19 TV UI/animations can remain intact while installing as a separate `jp.jun.iptv` package named `Jun IPTV`.

Alpha1 deliberately does not add YouTube/KICK/TVer/multiview/secret mode yet. Those are added only after the stock interaction flow is confirmed on TS-401.

Test APK publication target: `https://github.com/ajiousama/himitsu/raw/main/j.apk`.
