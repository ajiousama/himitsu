# epg system

Common EPG engine for the FreeWiFi aggregate.

The canonical build helpers live under `epg/`. The public `guides.xml` at repository root remains the compatibility output consumed by APTV and existing clients.

Subsystems feed the shared EPG:
- ganble / public sports
- radio
- rakuten
- youtube fallback/live-camera labels
- vod5 / KICK
- ehime_catv
- tv / TVer
