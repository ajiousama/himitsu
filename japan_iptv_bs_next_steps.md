# Japan IPTV BS Research Next Steps

This file tracks the next URL-free research work for BS-related candidates.

## Goal

Keep BS research as a metadata and classification registry, not a playback list.

## Scope

- Free/general BS candidates
- BS public-service/name mapping candidates
- BS premium groups as metadata only
- BS/CS crossover groups, such as anime, movie, and shopping channels
- Legacy source families for comparison only

## Do not add

- Direct stream URLs
- Token, vhash, ac_tk, p2p, or p5p values
- Hidden/private source data
- Detailed premium playback slug lists

## Recommended order

1. Confirm free/general BS naming and EPG IDs.
2. Compare BS free/general entries across existing URL-free source notes.
3. Separate premium BS groups into metadata-only rows.
4. Move anime/kids crossover entries to the later anime/kids registry.
5. Move movie/specialty crossover entries to the later CS movie registry.
